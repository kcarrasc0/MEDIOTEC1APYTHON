# 🐍 Construindo Interfaces com Python (CustomTkinter)

Bem-vindo ao nosso ambiente de desenvolvimento! Neste repositório, vamos dar vida aos nossos protótipos do Figma e construir aplicações desktop reais utilizando Python e a biblioteca **CustomTkinter**.

Como estamos utilizando o GitHub Codespaces (que é um servidor na nuvem sem uma tela física), preparamos um **Desktop Virtual** especial neste repositório. Isso permitirá que você veja a interface gráfica do seu aplicativo rodando diretamente em uma nova aba do seu navegador.

---

## Como rodar e visualizar seu código

Siga o passo a passo abaixo para executar o seu projeto e acessar a tela virtual:

1. **Inicie o aplicativo:** Abra o arquivo `main.py` e clique no botão **Run (Play)** no canto superior direito, ou digite `python main.py` no terminal.
2. **Deixe rodando:** Você vai notar que o código começou a rodar no terminal, mas a janela do programa não apareceu na tela do código. Isso é normal! O aplicativo está ativo e esperando por você.
3. **Abra o painel de Portas:** Na parte inferior da tela do Codespaces (ao lado da aba "Terminal"), clique na aba **Portas (Ports)**.
4. **Encontre o monitor virtual:** Na lista de portas ativas, procure por uma chamada **Desktop Virtual (Tela) - 6080**.
5. **Acesse pelo navegador:** Passe o mouse sobre essa porta e clique no ícone de "globo" (**Open in Browser / Abrir no Navegador**).
6. **Veja a mágica acontecer:** Uma nova aba se abrirá mostrando a tela de um computador (via noVNC). Lá dentro, você verá a janela do seu aplicativo CustomTkinter rodando perfeitamente!

---

### Dicas Importantes para a Aula

* **Paciência no primeiro carregamento:** O primeiro acesso ao Codespaces neste repositório pode demorar um pouco mais do que o normal, pois ele está instalando o seu "monitor virtual". Nas próximas vezes, o carregamento será rápido.
* **Parando o código:** Para fechar o seu aplicativo e testar novas mudanças no código, vá até o terminal onde você rodou o `main.py` e pressione `Ctrl + C` para interromper a execução antes de rodar novamente.
* **Ajuste o layout:** Lembre-se de pensar na sua tela como uma composição de blocos (Frames). Revise seus protótipos no Figma antes de começar a codificar!

Bom trabalho e divirta-se programando!
